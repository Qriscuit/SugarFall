# Sugarfall — Mabel storefront draft

Prepared 4 November 2026. Mabel is the approved Sugarfall mascot. This revision adds a mascot icon, a mascot feature graphic and a full-body character turnaround, and revises the listing around play, physics and upgrades without a fixed count of areas, levels or trays.

Open [preview.html](preview.html) to review the assets and exact listing copy together. Extract the whole review folder first if using the ZIP.

The new artwork is made with the built-in imagegen tool. The original in-game `PLINKO/data/art/host/mabel_welcome.png` is the character identity reference. Mabel retains her brown eyes, freckles, chestnut bun, mint collared puff-sleeve dress, cream strawberry apron and copper buttons. The turnaround proposes a complete lower body, including a below-knee skirt and brown shoes, because the earlier portrait did not show it.

The icon and banner are promotional assets for review. They do not replace the in-game portrait or the Android launcher in this task. The full description describes Mabel's actual introductory role; continued appearances and daily challenges remain proposals in `planned-copy.md`.

The authoritative listing fields and claim evidence are in `PLINKO/docs/store/STORE_COPY.md` and `store_copy.en-US.json`. The mascot decision and reuse rules are in `PLINKO/docs/store/MABEL_MASCOT.md`.

The earlier `storefront-v1` package remains dated evidence. Its screenshots are actual RC2 desktop captures, with Android comparison still open and later interface changes requiring affected replacements. See the [earlier Drive package](https://drive.google.com/file/d/14SdcC4t36EbDhBYN0bOPlaDvlobTzO-p/view). This v2 package does not supply new gameplay screenshots or record a Play Console upload.
