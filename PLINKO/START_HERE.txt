WINDOWS: OPEN AND PLAY
1. Extract this ZIP fully to a normal writable folder, for example Documents/Sugarfall. Do not run inside the ZIP.
2. Download the standard Godot 4.6.3 editor from the official release page:
   https://github.com/godotengine/godot-builds/releases/tag/4.6.3-stable
   No C#/.NET edition is required. This project uses GDScript and the Compatibility renderer.
3. Open Godot Project Manager, click Import and select project.godot at THIS folder's root. Let Godot import the SVG textures. Use F5 to run the game.
4. Edit scripts/main.gd for gameplay/UI, scripts/upgrade_map.gd for the map, scripts/run_snapshot.gd for saves, scripts/tone_bank.gd for sound, data/*.json for tuning, and data/art/*.svg for original cached vector art.
5. The .godot folder generated by the editor is a cache and is intentionally not included here.

WHAT IS CURRENT
v0.5 is the performance revision of v0.4:10-second fresh runs,6baseline hits per normal peg, free retries and useful damage earnings. The earlier60-second design is historical. v0.5 caches visuals/sounds and optimizes collision candidates without changing those rules. Read CHANGELOG.txt, PERFORMANCE_NOTES.txt and BLOCKERS.txt.
The user reported lag on Pixel6. Cloud CPU benchmarks improved, but the optimized build's actual Pixel6 GPU/frame pacing/thermal performance is NOT verified. Setup → Performance Display provides a default-off local diagnostic overlay. No telemetry leaves the device.

In Bakery, Home menu → Help → Learn with Mabel replays only the guide without resetting progress. Main/Fresh Test selection is retired.

IMPORTANT SIGNING NOTE
No private signing key, password, token or credential is included. Create and securely retain your own development/release keystore for future exports. A differently signed APK cannot update the existing same-package APK in place. Without its old matching signing key, use a separate application/package ID for local tests or plan migration carefully. Uninstalling can erase local game progress. The delivered v0.5 APK matches the recovered v0.3/v0.4 signer, not the earlier lost original signer. No store publishing is configured or authorized.
