# Native area menu frames and Jam Burst sprite

Four new assets generated by the built-in `image_gen` tool on 3 November 2026, then copied into the project without pixel modification. The exact generation prompts, original paths, runtime locations and native-byte/alpha inspection are in [sources.json](sources.json), [jam-donut-source.json](jam-donut-source.json) and [native-validation.json](native-validation.json).

The three menu boards have quiet blank faces and small themed corner scenery. Godot keeps the corners at a uniform scale and stretches the middle spans. Artwork never contains the Settings/Pause title or live controls. The Jam Burst doughnut uses a distinct berry center that remains legible at small ball/icon sizes.

`inspect_assets.py` reads image metadata and hashes and supplies import settings. It does not edit or resize pixels. Runtime integration is documented in [AREA_MENU_ART.md](../../PLINKO/docs/AREA_MENU_ART.md).
